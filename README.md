# Trader

A small web app where two people trade items.

## How it works

1. Trader A and Trader B enter their names.
2. Each person enters the item they want to trade.
3. Click **Propose Trade**.
4. Both sides click **Accept Trade**.
5. Once both accept, the items are swapped.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
